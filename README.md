# Hackathon — Gestion des flux touristiques

## Équipe 6

Ce projet de hackathon vise à mieux répartir les flux touristiques en proposant aux visiteurs des alternatives adaptées à leur profil.

## Objectifs

- Réorienter les flux touristiques d’un site à un autre.
- Profiler les visiteurs d’une zone touristique pour mieux comprendre leurs attentes et leurs préférences.

## Solution envisagée

Récolter des données client pour proposer, de manière automatisée, des alternatives touristiques personnalisées.

La démarche repose sur trois étapes :

1. Recueillir des données sur les visiteurs, leurs préférences et leurs besoins.
2. Utiliser ces données pour établir des profils de visiteurs.
3. Recommander automatiquement d’autres sites ou activités adaptés à chaque profil.

## Résultat attendu

Aider les visiteurs à découvrir des alternatives pertinentes tout en favorisant une meilleure répartition de la fréquentation entre les sites touristiques.
